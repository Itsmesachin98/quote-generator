# ✨ Quote Generator

A fun and inspiring quote generator that fetches quotes from a public API and displays them beautifully on screen. You can also share the quote directly on Twitter with a single click!

🔗 **Live Site:** [quote-generator-liard-sigma.vercel.app](https://quote-generator-liard-sigma.vercel.app)

---

## 🚀 Features

-   Random quotes fetched from a public API
-   Displays the author of the quote (or `Unknown` if not available)
-   Responsive and clean UI
-   Tweet the quote with one click
-   New quote button to refresh inspiration anytime
-   Simple, fast, and lightweight

## 🧠 How It Works

1. On page load, it fetches quotes from the API.
2. Displays a randomly chosen quote and its author.
3. Adjusts styling if the quote is long.
4. Users can:
    - Click "New Quote" to fetch another one.
    - Click the Twitter icon to tweet the quote.
